###	Chapter 3 - Credit-Based Shaper


==================== Start sync
A-side:~$ ptp4l -P2Hi enp0s30f4 -f ~/gPTP.cfg --step_threshold=1 -m
B-side:~$ ptp4l -P2Hi enp0s30f4 -f ~/gPTP.cfg --step_threshold=1 -m
A-side:~$ phc2sys -s enp0s30f4 -O 0 -c CLOCK_REALTIME --step_threshold=1 --transportSpecific=1 -w -m
B-side:~$ phc2sys -s enp0s30f4 -O 0 -c CLOCK_REALTIME --step_threshold=1 --transportSpecific=1 -w -m

==================== Check queues
A-side:~$ ls /sys/class/net/enp0s30f4/queues
rx-0 rx-1 rx-2 rx-3 rx-4 rx-5 tx-0 tx-1 tx-2 tx-3 

==================== Clear qdisc
A-side:~$ tc qdisc del dev enp0s30f4 root
B-side:~$ tc qdisc del dev enp0s30f4 root

==================== Map traffic
