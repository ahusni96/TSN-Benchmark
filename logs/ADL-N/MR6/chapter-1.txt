
==================== Change MAC address
A-side:~$ ip link set dev enp0s30f4 down
A-side:~$ ip link set dev enp0s30f4 addr aa:00:aa:00:aa:11
A-side:~$ ip link set dev enp0s30f4 up
A-side:~$ ip link show dev enp0s30f4 | grep -i link/ether | xargs
MAC Address A: aa:00:aa:00:aa:11

B-side:~$ ip link set dev enp0s30f4 down
B-side:~$ ip link set dev enp0s30f4 addr aa:00:aa:00:aa:22
B-side:~$ ip link set dev enp0s30f4 up
B-side:~$ ip link show dev enp0s30f4 | grep -i link/ether | xargs
MAC Address B: aa:00:aa:00:aa:22
