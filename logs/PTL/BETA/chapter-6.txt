###	Chapter 6 - Qbu Frame Preemption

==================== Restart NetworkManager
A-side:~$ systemctl restart NetworkManager
B-side:~$ systemctl restart NetworkManager

==================== Start sync

==================== Clear qdisc
A-side:~$ tc qdisc del dev enp1s0 root
B-side:~$ tc qdisc del dev enp1s0 root

==================== Enable FPE (ETHTOOL)
A-side:~$ ethtool --set-mm enp1s0 pmac-enabled on tx-enabled on
B-side:~$ ethtool --set-mm enp1s0 pmac-enabled on tx-enabled on

==================== Verify Frame Preempt
A-side:~$ ethtool --set-mm enp1s0 verify-enabled on
B-side:~$ ethtool --set-mm enp1s0 verify-enabled on

==================== Configure TXQ PRIO
A-side:~$ ethtool --set-priv-flags enp1s0 reverse-tsn-txq-prio on
A-side:~$ ethtool --show-priv-flags enp1s0
Private flags for enp1s0:
legacy-rx           : off
reverse-tsn-txq-prio: on

==================== Set IP address
A-side:~$ ifconfig enp1s0 192.168.1.11
A-side:~$ ip -4 addr show enp1s0 | grep -oP "(?<=inet\s)\d+(\.\d+){3}"
IP Address: 192.168.1.11

B-side:~$ ifconfig enp1s0 192.168.1.22
B-side:~$ ip -4 addr show enp1s0 | grep -oP "(?<=inet\s)\d+(\.\d+){3}"
IP Address: 192.168.1.22
