###	Chapter 1 - Setup


==================== Change MAC address
A-side:~$ ip link set dev enp1s0 down
A-side:~$ ip link set dev enp1s0 addr aa:00:aa:00:aa:11
A-side:~$ ip link set dev enp1s0 up
A-side:~$ ip link show dev enp1s0 | grep -i link/ether | xargs
MAC Address A: aa:00:aa:00:aa:11

B-side:~$ ip link set dev enp1s0 down
B-side:~$ ip link set dev enp1s0 addr aa:00:aa:00:aa:22
B-side:~$ ip link set dev enp1s0 up
B-side:~$ ip link show dev enp1s0 | grep -i link/ether | xargs
MAC Address B: aa:00:aa:00:aa:22

==================== Disable flow-control
A-side:~$ ethtool -A enp1s0 autoneg off rx off tx off
A-side:~$ ethtool -a enp1s0
Pause parameters for enp1s0:
Autonegotiate:	off
RX:		off

B-side:~$ ethtool -A enp1s0 autoneg off rx off tx off
