###	Chapter 6 - Qbu Frame Preemption


==================== Start sync
A-side:~$ ptp4l -P2Hi enp85s0 -f ~/gPTP.cfg --step_threshold=1 -m --first_step_threshold=0.0
B-side:~$ ptp4l -P2Hi enp85s0 -f ~/gPTP.cfg --step_threshold=1 -m --first_step_threshold=0.0
A-side:~$ phc2sys -s enp85s0 -O 0 -c CLOCK_REALTIME --step_threshold=1 --transportSpecific=1 -w -m --first_step_threshold=0.0
B-side:~$ phc2sys -s enp85s0 -O 0 -c CLOCK_REALTIME --step_threshold=1 --transportSpecific=1 -w -m --first_step_threshold=0.0

==================== Enable Frame Preemption
A-side:~$ ethtool --set-frame-preemption enp85s0 fp on
A-side:~$ ethtool --show-frame-preemption enp85s0
Frame preemption settings for enp85s0:
	enabled: enabled
	additional fragment size: 68
	verified: 0
	verification disabled: 1

==================== Clear qdisc
A-side:~$ tc qdisc del dev enp85s0 root
B-side:~$ tc qdisc del dev enp85s0 root

==================== Add qdisc
A-side:~$ BASE=$(date +%s%N) && tc qdisc add dev enp85s0 parent root stab overhead 24 handle 100 taprio num_tc 4 map 0 1 2 3 3 3 3 3 3 3 3 3 3 3 3 3 queues 1@0 1@1 1@2 1@3 base-time $BASE sched-entry S 0f 5000000 preempt 1100 flags 0x2


==================== Stop sync
A-side:~$ pkill phc2sys
A-side:~$ pkill ptp4l
B-side:~$ pkill phc2sys
B-side:~$ pkill ptp4l
