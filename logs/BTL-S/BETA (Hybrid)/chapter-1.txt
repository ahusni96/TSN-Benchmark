
==================== Change MAC address
A-side:~$ ip link set dev enp2s0 down
A-side:~$ ip link set dev enp2s0 addr aa:00:aa:00:aa:11
A-side:~$ ip link set dev enp2s0 up
A-side:~$ ip link show dev enp2s0 | grep -i link/ether | xargs
MAC Address A: aa:00:aa:00:aa:11

B-side:~$ ip link set dev enp2s0 down
B-side:~$ ip link set dev enp2s0 addr aa:00:aa:00:aa:22
B-side:~$ ip link set dev enp2s0 up
B-side:~$ ip link show dev enp2s0 | grep -i link/ether | xargs
MAC Address B: aa:00:aa:00:aa:22
